# ☕ Coffee Shop Sales Analysis — Excel

## 📌 Project Overview

This project focuses on analyzing coffee shop sales data using **Microsoft Excel** to understand sales performance, customer ordering patterns, product performance, store-wise sales, and time-based trends.

An interactive Excel dashboard was created using **Pivot Tables, Pivot Charts, KPIs, and Slicers** to present the analysis in an easy-to-understand format.

---

## 🎯 Project Objective

The main objectives of this project are to:

* Analyze overall coffee shop sales performance.
* Understand customer ordering patterns.
* Identify top-performing products and product categories.
* Compare sales performance across different store locations.
* Analyze order trends by day and hour.
* Build an interactive dashboard for business reporting and decision-making.

## 📈 Analysis Performed

### 1. Sales Analysis

* Analyzed overall sales performance.
* Compared sales across different store locations.
* Examined monthly sales trends.

### 2. Product Analysis

* Identified top-performing products.
* Analyzed sales across different product categories.
* Examined product-level contribution to overall sales.

### 3. Customer & Order Analysis

* Analyzed total customer footfall.
* Examined average bill and order size.
* Studied transaction size distribution.

### 4. Time-Based Analysis

* Analyzed orders by day of the week.
* Examined hourly order patterns.
* Identified periods with higher and lower order activity.

### 5. Store Performance

* Compared performance across coffee shop locations.
* Analyzed sales and customer activity by store.
